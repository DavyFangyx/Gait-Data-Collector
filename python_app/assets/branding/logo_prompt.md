# Logo Prompt Spec

用于后续调用 imagegen 继续细化品牌资产的提示词基线：

- 产品名称：四机位同步采集系统
- 关键词：四通道同步、视觉采集、帧同步、实验控制台、专业桌面软件、几何科技感
- 视觉要求：
  - 不要拟物相机图标
  - 不要通用互联网公司 Logo 风格
  - 以四个通道节点、中心镜头孔径、同步脉冲线组成核心图形
  - 适配深色监控台界面
  - 主色为深石墨、琥珀、青绿、冷青蓝
  - 图形需要在 16px 到 256px 范围内保持识别度
- 字标文案：四机位同步采集系统
- 字标风格：中文无衬线、稳重、工程化、非娱乐化
- 交付要求：
  - 方形主图标
  - 横版字标
  - 深底版与浅底版
  - 软件图标可用的 ICO 导出

当前仓库内的品牌资产由本地几何生成脚本输出，可直接用于窗口标题栏、README 和应用图标；未来若启用 imagegen，可基于上述规格继续升级为更精细的视觉版本。
